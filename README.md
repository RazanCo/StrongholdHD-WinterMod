# Stronghold HD - Winter Mod
Original Stronghold in Winter. This mod adds visual changes for Stronghold HD. Rework of original textures for Winter season. The game appearance is Brighter.

# How to Install from Google Drive
Link to a Stronghold HD - Winter Mod zip folder - https://drive.google.com/file/d/1CJohyBhCJe7uLJ7fA7eA_V5VxTxxQ2IN/view?usp=sharing
  - Download the Stronghold HD Winter Mod 1.1 zip folder and open
  - extract gm and gfx folders from "Winter mod files" folder to Stronghold HD install location on your system. (recommended to make a backup)
  - After replacing gm and gfx folders you can immediately start playing Stronghold HD.
# How To Install from GitHub
  - Download the Stronghold HD Winter Mod 1.1 zip folder from "Releases" tab.
  - Open zip and extract gm and gfx folders.

OR
  - Download the Stronghold HD Winter Mod 1.1 zip folder by pressing green code button.
  - Open zip and extract gm and gfx folders.
  
Basic installation:
  - Go to Stronghold HD game files directory (place where you have the game installed)
  - extract gm and gfx folders from "Winter mod files" folder to Stronghold HD install location on your system. (recommended to make a backup)
  - After replacing gm and gfx folders you can immediately start playing Stronghold HD.

If using Steam:
  - go to Stronghold HD in steam library
  - click setting icon -> manage -> browse local files
  - find gm and gfx folders and replace them with downloaded gm and gfx folders from "Winter mod files" directory. (recommended to make a backup)
  - After replacing gm and gfx folders you can immediately start playing Stronghold HD.

# V1.1 Changes
  - More snow.
  - Reworked the textures to be more uniform.
  - All buildings now have the same amount of snow covering them.
  - Added contrast to differentiate objects.
  - Added thin ice to water and moats.
  - Froze the waterfalls and water fords.
  - Changed animations and appearance of trees and bushes.
  - Added snowmen.
  - Changed animations of caged dogs and dancing bears.
  - Wolves and Rabbits have white fur.
  - Woodcutters now wear red hats.
  - Added Christmas ornaments to buildings.
  - Added Christmas trees as decorations.
  - Added snow to goods on the stockpile
  - Changed windmill animation, now it has snow on the roof.
  - Added snow to engineer tents and engines of war.
  - Added snow to crops on farms.
  - Few visual fixes.
