Stronghold HD - Winter Mod 1.1 zip folder contents:
    Backup files - backup of the original gm and gfx files Stronghold HD.
    Winter mod files - winter version of gm and gfx files for Stronghold HD.
    Read me - this.

To Install:
    - extract gm and gfx folders from "Winter mod files" folder to Stronghold HD install location on your system.
    - replace all files by clicking replace all.
    - game is ready to play.

To Uninstall:
    - open "Backup files" folder and extract gm and gfx folders to Stronghold HD install location on your system.
    - replace all files by clicking replace all.
    - game is ready to play.
